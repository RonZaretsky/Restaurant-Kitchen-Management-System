# תיקיית הביקורת

כאן נשמרים העותקים המוערים של המסמכים, כלומר הקבצים שבהם הכותבים מסמנים הערות תוך כדי
קריאה. **תיקייה זו איננה מוחרגת מ-git**, בשונה מ-`output/`, ולכן כל מה שיושב בה נשמר
ומגובה.

ההבחנה מכוונת: את המסמכים שב-`output/` ניתן לשחזר במלואם בפקודה אחת, ואילו עותק מוער הוא
עבודת ידיים שאם תאבד לא ניתן לייצר אותה מחדש.

## מוסכמות

**שם הקובץ** כולל את שם המסמך ואת שם המעיר, לדוגמה
`מסמך-עיצוב-פתרון-עם-הערות-של-אופק.docx`.

**קובץ מוער איננו נמחק ואיננו נדרס**, גם לאחר שכל ההערות שבו טופלו וגם כאשר תוכנו התיישן.
הוא המקור של ההערות, וההכרעות שהתקבלו בעקבותיהן מתועדות ב-`../review-register.md`
המפנה אליו.

**הערות** נכתבות כהערות Word, ופותחות בתחילית המסווגת את סוג ההערה:

| התחילית | המשמעות |
|---|---|
| `ליקוי:` | פער משמעותי החוסם את סיום העבודה על המסמך |
| `שיפור:` | פער סגנוני שאיננו חוסם |
| `הערה:` | מטא-הערה של הכותב |
| `לבדוק:` | שאלה הדורשת אימות מול קוד הפרויקט |

**צבע הטקסט** בגוף המסמך מסמן מי אחראי עליו:

| הצבע | המשמעות |
|---|---|
| ירוק | טקסט שהמעיר הוסיף או ערך במהלך הקריאה |
| סגול | טקסט שהמעיר יערוך בעצמו בהמשך |

## מאיזו גרסה נבנה עותק מוער

לכל מעבר ביקורת מתויגת בגיט הגרסה שממנה נבנה העותק, ולכן ניתן לשחזר בדיוק את המסמך
שנקרא, גם לאחר שהמקור התקדם:

```powershell
git checkout review-base-ofek-1
powershell -File "מסמכים\הגשה\build-tools\build-docs.ps1"
```

התג של כל מעבר רשום בכותרת של `../review-register.md`.
